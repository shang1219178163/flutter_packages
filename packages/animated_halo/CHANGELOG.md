## 1.0.0

- First release of `AnimatedHalo`: a pulsing halo ring recreated frame-by-frame
  from a 72×72, 60fps, 0–89 frame reference animation.
- Configurable `size`, `spacing`, `strokeWidth`, `innerStrokeWidth`, `duration`,
  colors, and a `child` clipped to a circle inside the inner ring.
- Includes an example app with live controls.
